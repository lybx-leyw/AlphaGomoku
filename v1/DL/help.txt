# Python语法清单及简单示例

## 1. 基础语法差异

### 注释
```python
# 单行注释（Python使用#而不是//）
"""
多行注释
使用三引号
"""
```

### 打印输出
```python
print("Hello, World!")  # 不需要分号，不需要printf格式
name = "Alice"
print(f"Hello, {name}")  # f-string格式化（推荐）
print("Hello, " + name)  # 字符串拼接
```

## 2. 变量和数据类型

### 变量声明（无需类型声明）
```python
# 整数
age = 25

# 浮点数
height = 1.75

# 字符串
name = "John"

# 布尔值
is_student = True

# 空值
nothing = None
```

### 基本数据类型
```python
# 列表（类似数组，但更灵活）
fruits = ["apple", "banana", "orange"]
fruits.append("grape")  # 添加元素

# 元组（不可变列表）
coordinates = (10, 20)

# 字典（键值对）
person = {"name": "John", "age": 30}

# 集合（无序不重复）
unique_numbers = {1, 2, 3, 3, 2}  # 结果为{1, 2, 3}
```

## 3. 控制结构

### 条件语句
```python
# if-elif-else（注意冒号和缩进）
score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
else:
    print("加油")
```

### 循环
```python
# for循环（遍历序列）
fruits = ["apple", "banana", "orange"]
for fruit in fruits:
    print(fruit)

# 范围循环
for i in range(5):  # 0到4
    print(i)

# while循环
count = 0
while count < 5:
    print(count)
    count += 1  # 没有++运算符
```

## 4. 函数定义

```python
# 定义函数
def add(a, b):
    return a + b

# 调用函数
result = add(3, 5)
print(result)  # 输出8

# 带默认参数的函数
def greet(name, message="Hello"):
    return f"{message}, {name}!"

print(greet("Alice"))  # Hello, Alice!
print(greet("Bob", "Hi"))  # Hi, Bob!
```

## 7. 异常处理

```python
try:
    number = int(input("请输入一个数字: "))
    result = 10 / number
    print(f"结果是: {result}")
except ValueError:
    print("请输入有效的数字!")
except ZeroDivisionError:
    print("不能除以零!")
```

## 8. 类与对象

```python
# 定义类
class Person:
    def __init__(self, name, age):  # 构造函数
        self.name = name
        self.age = age
    
    def introduce(self):
        return f"我叫{self.name}, 今年{self.age}岁"

# 创建对象
person1 = Person("张三", 25)
print(person1.introduce())
```

## 9. 列表操作（重要！）

```python
# 创建列表
numbers = [1, 2, 3, 4, 5]

# 切片操作
print(numbers[1:3])    # [2, 3]
print(numbers[-1])     # 5（最后一个元素）

# 列表推导式（强大特性）
squares = [x**2 for x in numbers]  # [1, 4, 9, 16, 25]

# 过滤
even_numbers = [x for x in numbers if x % 2 == 0]  # [2, 4]
```

## 10. 模块导入

## 从C到Python的重要转变：

1. **不需要分号** - 行尾的分号是可选的（通常省略）
2. **代码块用缩进** - 不使用花括号{}
3. **变量无类型声明** - 直接赋值即可
4. **没有指针概念** - Python自动管理内存
5. **数组变成列表** - 更灵活，可以包含不同类型
6. **字符串处理更简单** - 不需要字符数组

## 简单完整示例

```python
# 计算阶乘的函数
def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n - 1)

# 主程序
if __name__ == "__main__":
    try:
        num = int(input("请输入一个非负整数: "))
        if num < 0:
            print("请输入非负整数!")
        else:
            result = factorial(num)
            print(f"{num}的阶乘是: {result}")
    except ValueError:
        print("请输入有效的整数!")
```

Matplotlib 核心函数详解
1. plt.figure() - 创建画布
python
plt.figure(figsize=(12, 4), dpi=100, facecolor='white')
参数说明：
figsize=(宽, 高)：控制整个图表的大小（英寸）
dpi=100：分辨率，数值越大图像越清晰
facecolor='white'：背景颜色
edgecolor='black'：边框颜色
效果： 创建一个空白的绘图区域，就像准备一张画纸
2. plt.subplot() - 创建子图
python
plt.subplot(1, 2, 1)  # 1行2列的第1个子图
参数说明：
第一个数字：行数
第二个数字：列数
第三个数字：子图位置（从左上到右下编号）
效果： 把画布分成多个小区域，可以在不同区域画不同的图表
3. plt.plot() - 绘制折线图
python
plt.plot(x_data, y_data, 'b-', linewidth=2, label='训练损失', alpha=0.8)
参数说明：
x_data, y_data：X轴和Y轴的数据
'b-'：格式字符串
b = blue（蓝色），其他：r=red, g=green, k=black
- = 实线，其他：--=虚线, :=点线, -.=点划线
linewidth=2：线条粗细
label='训练损失'：图例标签
alpha=0.8：透明度（0-1之间）
marker='o'：数据点标记（o=圆圈, s=方块, ^=三角形）
效果： 用折线连接数据点，显示趋势变化
4. plt.title(), plt.xlabel(), plt.ylabel() - 添加文字
python
plt.title('训练损失曲线', fontsize=14, fontweight='bold')
plt.xlabel('训练轮次', fontsize=12)
plt.ylabel('损失值', fontsize=12)
参数说明：
第一个参数：文字内容
fontsize=14：字体大小
fontweight='bold'：字体粗细（'normal'正常, 'bold'粗体）
color='red'：文字颜色
5. plt.grid() - 添加网格
python
plt.grid(True, alpha=0.3, linestyle='--')
参数说明：
True/False：是否显示网格
alpha=0.3：网格线透明度
linestyle='--'：网格线样式
color='gray'：网格线颜色
效果： 让数据点位置更容易读取
6. plt.legend() - 显示图例
python
plt.legend(loc='upper right', frameon=True, fontsize=10)
参数说明：
loc='upper right'：位置（'best'自动选择, 'upper left'左上等）
frameon=True：是否显示图例边框
fontsize=10：图例字体大小
