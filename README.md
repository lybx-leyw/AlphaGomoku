# 基于AlphaGo网络风格的五子棋AI探索（AlphaGomoku）

## 项目简介

AlphaGomoku 是一个基于深度学习与强化学习的五子棋人工智能项目，采用“策略网络+价值网络”的AlphaGo风格双网络架构。快速开始版提供了精简的代码和预训练模型，方便用户立即体验AI对战的乐趣。

## 核心功能

### 1. 双网络架构
- **策略网络（trick.pkl）**：预测最优落子位置
- **价值网络（value.pkl）**：评估棋盘局势优劣

### 2. 游戏特性
- 15×15标准五子棋棋盘
- 人类 vs AI 对战模式
- 实时棋盘可视化
- 自动胜负判断
- 五子连线高亮显示

## 预训练模型

### 模型规格
| 模型        | 大小     | 作用   | 训练数据量  |
| --------- | ------ | ---- | ------ |
| trick.pkl | 1.2 MB | 策略网络 | 2万+ 对局 |
| value.pkl | 918 KB | 价值网络 | 相应数量对局 |

### 性能表现
- 策略网络预测准确率：约50%（对比随机 baseline 1/225）
- 平均思考时间：<0.5秒，可忽略不计

## 使用方法

### 运行游戏
```bash
# 进入快速开始目录
cd AlphaGomoku/quick-start

# 启动游戏
python game.py
```

### 游戏设置
运行 `game.py` 后，程序将引导您进行以下设置：

1. **选择AI难度**：
   - 程序显示：`AI难度介绍：1-简单决策AI，2-激进决策AI，3-平衡决策AI`
   - 输入提示：`请输入难度（1/2/3）`
   - 输入对应的数字选择难度级别

2. **设置AI先后手**：
   - 程序提示：`请输入AI的先后手（1，-1，2）`
   - 输入选项：
     - `1`：AI执黑先行
     - `-1`：AI执白后行
     - `2`：随机决定先后手

设置完成后，游戏将开始，棋盘会显示在控制台中。

## 技术演进

### 一、简单深度学习探索尝试（2025年11月）

#### 1. 基础网络探索（net1–net3）
- **设计思路**：采用三通道输入（黑子层、白子层、身份层）
- **核心问题**：卷积核太小（3×3），导致网络“近视”
- **主要发现**：
  - 模型过度关注局部块状战术
  - 缺乏全局视野和线性判断能力
  - 无法有效判断长距离连接

#### 2. 突破性改进（net4）
- **关键创新**：添加第四通道（全局层）
- **结构优化**：卷积核从3×3扩大到5×5（达到当时CPU计算极限）
- **显著优势**：
  - 攻防平衡性最佳
  - 全局判断能力显著提升
- **遗留问题**：边角处理能力薄弱（因缺少池化层）

#### 3. 结构探索（net5–net8）
**net5 – 攻击型网络**
- **改进点**：添加池化层
- **优点**：
  - 边界处理优于net4
  - 攻击性强，先手优势明显
- **缺点**：防御薄弱，缺乏有效的价值评估机制

**net6 – 价值增强型**
- **改进点**：增强价值评判属性
- **特点**：能克制net5，但真人实战效果不佳
- **结果**：总体表现仍不如net4

**net7 & net8 – 保守优化**
- **特点**：增加防守参数，可能导致策略过于保守
- **共同点**：边界处理更优
- **结果**：总体表现不如net4

#### 4. 实验性探索（net9–net13）
- **结果**：整体表现未达预期，效果不理想

### 二、DQN与AlphaGo风格探索尝试（2025年11月–12月）

#### 1. DQN探索（net14、net15）
- 尝试使用DQN算法对net4进行强化学习
- 结果：模型或能稳定击败net4但实际棋力不高，或棋力与net4相当，提升不明显
- 尝试结合DQN与模仿学习（模仿net4落子）进行模型蒸馏，但收敛极慢；由于五子棋逻辑复杂，在CPU上训练难以胜任

#### 2. AlphaGo探索（v2）
- 实现了基础的MCTS（蒙特卡洛树搜索），引入噪声以增加探索随机性
- 简单MCTS耗时严重，net4结合搜索深度为100的MCTS后，已可与部分网页版五子棋AI的“专家”级别打成平手
- MCTS能给出更优解，但模型学习能力差，面临与DQN类似的收敛难题
- 由于MCTS基于net4进行强化，而net4网络存在边界防御弱点，最终模型偶尔会在边界行棋，脱离主战场
- 因MCTS实现较为简陋，有时反而会指向更差的着法，因此暂移除了MCTS相关函数，计划系统学习MCTS原理后重新实现

总体而言，这一个半月在优化过程中遇到较多挑战。我们发现，要对已经具备人类棋手水平的net4进行进一步强化，难度极大。当前简陋的算法与CPU算力难以支撑模型训练。

### 三、高性能系统探索优化（2025年12月至今）

为了克服性能瓶颈，我们建立了v3版本，主要改进包括：

- 修改落子函数，支持 `tensor[paraLines, 4, 15, 15]` 格式，实现多局棋并行计算
- 优化深度训练数据准备逻辑，将数据填充为矩阵形式，利用向量运算实现122局棋局同时进行
- 使用PyTorch的DataLoader实现CPU上的OpenMP多线程优化
- 在深度学习训练中，表现出远优于v1和v2版本的训练速度

目前MCTS的多线程并行设计仍在研究中。未来，我们将继续探索在CPU算力限制下MCTS的高效实现，并在实践中进一步理解强化学习应对高复杂度游戏时的难点与策略。项目仍在不断优化中。

> 注：由于项目初衷并非仅为五子棋游玩设计，因此棋盘显示仍采用简洁的 `print()` 输出。
